## what i build

- **[ATPS](https://github.com/samaasrr/atps)** — attack path simulator. graph-based threat modeling engine with ML-ranked risk paths and what-if patch analysis
- **[job-alert-tool](https://github.com/samaasrr/job-alert-tool)** — automated job scraper with Ollama-powered cover letter drafts, emailed on a schedule
- **phishing-detector** — DistilBERT fine-tuned on 82k emails, 95% accuracy, Streamlit UI
- **portcullis** — C-based port scanner, multithreaded, banner grabbing, TTL-based OS detection
